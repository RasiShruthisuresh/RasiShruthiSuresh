## About

I'm a developer working at the intersection of machine learning, natural language processing, and privacy engineering. My work centers on building tools that extract meaningful signal from unstructured, real-world text — while treating data privacy as a design constraint rather than an afterthought.

Most of my recent projects fall into two buckets:

- **Understanding people through text** — analyzing emotional and mental-health signals in social media content and other user-generated text, using NLP techniques to surface patterns that aren't obvious from a manual read.
- **Protecting people in text** — building tools that detect and redact personally identifiable information across multiple languages and scripts, so that data can be used and shared responsibly.

I care about building things that work on real, messy data — mixed scripts, transliterated text, inconsistent formatting — rather than only the clean, English-first cases most tooling is designed around.

## Projects

### [marai](https://github.com/RasiShruthisuresh/marai)
A multilingual PII detection and redaction library covering Tamil, Arabic, Arabizi, and English text — including mixed-script and transliterated input that most English-first tools miss. Ships with a zero-dependency, rules-based core for structured PII (emails, phone numbers, national IDs like Aadhaar and Emirates ID), plus an optional local model layer (built on GLiNER) for detecting names and addresses. Everything runs locally, so sensitive data never leaves the machine.

### [anonymity-engine](https://github.com/RasiShruthisuresh/anonymity-engine)
A full-stack privacy engineering platform implementing modern data anonymization techniques, built to help teams anonymize datasets in line with current data protection standards.

### [MentalHealthAnalysis](https://github.com/RasiShruthisuresh/MentalHealthAnalysis)
Analyzes users' mental health indicators based on the content they've posted or consumed on social media, using the text itself as a signal rather than relying on self-reported data.

### [Emotion_Analysis](https://github.com/RasiShruthisuresh/Emotion_Analysis)
Detects and classifies emotional content in text data, applying NLP techniques to surface sentiment and emotion patterns.

### [MiniBankManagementSystem](https://github.com/RasiShruthisuresh/MiniBankManagementSystem)
A banking management system built in PHP, covering core account and transaction management functionality.

### [B99diversityanalysis](https://github.com/RasiShruthisuresh/B99diversityanalysis)
A Jupyter notebook exploring diversity analysis on a dataset, from data cleaning through visualization.
